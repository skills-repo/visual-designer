# Brand Designer — 品牌设计

> 品牌不是 Logo，是用户每次接触你产品时的感受总和。好的品牌设计让产品在用户心中占据一个清晰的位置，让「看起来专业」不再靠运气。本技能覆盖从品牌策略到视觉系统的完整流程。

## 能力

- **品牌策略**：品牌定位、核心价值提炼、品牌个性定义、竞争差异化
- **Logo 设计**：文字标/图形标/组合标、网格制图、最小尺寸规范、多场景适配
- **色彩系统**：主色/辅色/中性色、色彩心理学、无障碍对比度、深色模式
- **品牌手册**：品牌指南文档、使用规范、反例说明、模板系统
- **品牌触达点**：网站/App/社交媒体/邮件/印刷品的一致性设计

## 使用方式

在 Claude Code 中使用 `/brand-designer` 调用。

```
/brand-designer 帮我为这个 SaaS 产品设计品牌视觉方向
/brand-designer 评估这个 Logo 的识别性和多场景适配
/brand-designer 设计一套品牌色彩系统和使用规范
```

## 品牌设计流程

1. **策略** — 品牌定位 → 核心价值 → 个性关键词（3-5 个）
2. **探索** — 3 个视觉方向 moodboard → 选定方向
3. **核心资产** — Logo → 色彩 → 字体 → 图形元素
4. **系统化** — 组件库 → 使用规范 → 模板
5. **触达** — 各渠道适配 → 一致性检查

## 适用场景

- 独立开发者为新产品建立品牌视觉
- 开源项目的品牌形象设计
- 产品从 MVP 到正式版的品牌升级
- 个人开发者的个人品牌建设

## 限制

- 聚焦品牌视觉设计，不涉及品牌战略咨询和命名
- Logo 设计覆盖创意指导，不涉及商标注册和法律
- 品牌手册覆盖核心规范，不涉及完整 CI 手册（200 页级）
