# Illustrator — 插画创作

> 插画不只是「画得好看」——它是品牌视觉语言的核心载体。好的插画能替代千言万语，让产品更温暖、更有辨识度。本技能覆盖从创意到交付的插画创作流程。

## 能力

- **风格探索**：扁平/渐变/手绘/等距/涂鸦风格分析、风格参考板制作
- **构图原则**：三分法、视觉引导线、正负空间、画面平衡
- **色彩运用**：色板设计、对比与和谐、情绪传达、品牌色融入
- **矢量绘制**：钢笔工具、形状构建、路径优化、SVG 导出
- **插画系统**：组件化插画（头/身/道具）、一致性规范、场景库建设

## 使用方式

在 Claude Code 中使用 `/illustrator` 调用。

```
/illustrator 帮我设计这个品牌页面的插画风格方向
/illustrator 这组插画的构图有什么问题？帮我优化
/illustrator 设计一套适合 SaaS 产品的插画系统
```

## 创作流程

1. **需求理解** — 品牌调性、应用场景（Web/App/印刷）、目标受众
2. **风格探索** — 3 个风格方向 moodboard → 选定方向
3. **草图构思** — 构图探索、元素布局、视觉焦点
4. **精细绘制** — 矢量绘制、色彩填充、细节打磨
5. **交付** — 多格式导出、响应式适配、组件化整理

## 适用场景

- 独立开发者为产品添加品牌插画
- 落地页和营销物料的插画创作
- 产品空状态、加载页、404 页面的插画设计
- 社交媒体内容的视觉素材

## 限制

- 聚焦创意指导和设计规范，不涉及具体绘制工具的操作教程
- 风格探索覆盖主流风格，不涉及实验性艺术风格
- 不涉及 3D 建模和动画插画
