# Poster Design Generation — 海报设计

> 海报是信息传递的浓缩艺术——3 秒抓住眼球，5 秒传达核心信息。无论是活动推广、产品发布还是社交媒体，好的海报设计让信息自己说话。本技能覆盖海报设计的核心原则和实践。

## 能力

- **视觉层级**：主标题 > 副标题 > 关键信息 > 细节的视觉权重分配
- **信息架构**：核心信息提炼、信息分组、留白节奏
- **色彩冲击力**：主色调选择、对比色运用、品牌色约束
- **版式布局**：网格系统、对齐原则、视觉流向设计
- **多场景适配**：活动海报、产品发布、社交分享、印刷品规格


## 海报设计检查清单

1. **第一眼** — 3 米外能否看清主标题？
2. **信息流** — 视线是否按主标题→日期→详情自然流动？
3. **品牌** — 是否一眼能认出品牌/活动方？
4. **留白** — 是否有呼吸空间？元素是否过于拥挤？
5. **CTA** — 行动号召是否明确？（扫码/报名/了解更多）

## 适用场景

- 独立开发者做产品发布海报
- 技术社区活动推广物料
- 社交媒体营销海报
- 开源项目宣传素材

## 限制

- 聚焦设计原则和创意指导，不涉及具体工具操作
- 覆盖数字海报场景，不涉及大幅面印刷
- 不涉及动态海报和视频封面
