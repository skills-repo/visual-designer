# 品牌与字体系统 playbook

> 品牌不是 Logo，是一套让人一眼认出的视觉语言。本 playbook 给品牌资产清单与字体系统搭建方法。

## 1. 品牌视觉资产清单

```
□ 主色 + 辅助色（含色值/使用场景）
□ 字体组合（标题体 + 正文体，含替代方案）
□ Logo 与安全距离
□ 图形/图标语言
□ 图片/插画风格基调
□ 语气与排版基调（严谨/亲和/前卫）
```

**原则**：品牌规范先定义"能用的"和"禁止的"，下游才不会跑偏。

## 2. 字体系统搭建

```
1. 选标题体    — 有个性但不牺牲可读性（衬线显权威/无衬线显现代）
2. 选正文体    — 优先屏幕可读性，行高 1.5 左右
3. 定层级      — H1/H2/H3/正文/注释 的字号与字重映射
4. 定替代      — 目标字体不可用时回退到系统字体
5. 定字距      — 大标题可收紧字距，正文保持默认
```

**铁律**：正文永远优先可读性；展示字体只用于少量标题，别铺满正文。

## 3. 色彩使用纪律

- 主色用于品牌识别与关键操作，不滥用。
- 功能性色（成功/警告/错误）与品牌色分开，避免歧义。
- 文本与背景对比度满足 WCAG AA（正文 ≥4.5:1）。

## 4. 系统交付前检查清单

- [ ] 色彩/字体/Logo 规范成文且含禁用项
- [ ] 字体层级映射明确（含回退方案）
- [ ] 对比度达标（含无障碍）
- [ ] 跨物料抽样一致

## 5. 常见坑

- **字体过多**：一套物料用 4 种以上字体，杂乱无章。
- **忽视回退**：目标字体加载失败，排版崩坏。
- **色彩滥用**：主色铺满，失去强调作用。
- **无规范**：每次设计重新发明，品牌感丢失。

## 6. 相关子技能与层次边界

本 playbook（L2）沉淀**跨子技能共享**的品牌与字体系统搭建方法；具体执行落到各 L3 子技能：

- `skills/brand-designer/` — 品牌视觉资产清单与字体组合规范直接喂给品牌系统搭建（L2 §1/§2 → L3 品牌手册/字体层级映射）
- `skills/web-typography/` — 字体层级映射（H1-H6）与回退方案对应本 playbook §2 第 4-5 步
- `skills/poster-design-generation/` — 海报主标题字号与字距收紧复用本 playbook §2 字距铁律
- 兄弟 playbook：`references/design-principles.md` — 四大基础原则（CRAP）是本 playbook 色彩/字体纪律的上层依据

**层次边界**：L2 只讲"品牌字体系统怎么搭"的通用方法；具体某品牌的色值/字体选型、Web 流体字号实现等交给对应 L3 子技能。
